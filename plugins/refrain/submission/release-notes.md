# Refrain Plugin 0.3.0 local candidate

This source candidate adds explicit local sound production to the existing file-based authoring workflow. `produce init/inspect/apply` creates editable settings, reports exact group routing and sound/gain layers, and saves a new performance binding while retaining music, musical receipts and earlier binding/render evidence. The new production reference explains the six existing scene processors, first-match groups, native export, exact comparisons and the absence of automatic model hearing.

The candidate retains silent AIR@1 drafting, structural inspection, exact-parent continuation, independent previews and conversational MCP `hum`. It changes no sampled candidates or DSP algorithms. Parametric EQ, high-pass, per-voice routing, aux sends and general automation remain outside Scene@1. Source changes do not refresh an installed Plugin or activate the private runtime. This package has not been submitted, approved or published through the Plugins Directory.

The working source also adds a correspondence reference for `audition`, `respond`, `share`, and `receive`, plus actual MCP `audition` audio. Responses are optional, and audio-input acceptance remains host-specific and unverified. This reference update is a source candidate, not an installed Plugin update.
