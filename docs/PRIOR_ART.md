# Prior art and independent boundary

Refrain does not claim that AI-written music, MIDI generation, browser synthesis, score display, or MCP playback is novel on its own.

Known adjacent work includes MIDI-oriented MCP servers with piano-roll playback, live-coding music MCPs, DAW control integrations, prompt-to-song generators, and personalized song-gift services. Refrain's product center is different: the current conversational agent writes a portable, machine-readable air, and named motifs can return through an ongoing relationship or identity without a hidden composer or server-owned memory.

Implementation rules:

- do not copy another project's code, schema, assets, UI structure, or copy;
- keep piano roll, if ever added, as an optional developer inspection view rather than the public visual identity;
- derive public visuals from Refrain's source semantics, especially motif recurrence and voice relations;
- keep links and dated evidence here as the landscape is refreshed before publication.
