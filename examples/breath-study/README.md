# A little room between

An authored twelve-bar air: first light, reflection, landing.
The 36 melody pitches and beat onsets match the independent
[Breath study](../../apps/breath-study/README.md). The experiment manipulates
its own synthetic work; these exact Artifact@3 files remain separate sampled
companions.

- Nylon: [canonical AIR](../../fixtures/air-v1/breath-study.air.json) · [portable artifact](a-little-room-between.refrain.json)
- Shinyguitar archtop: [canonical AIR](../../fixtures/air-v1/breath-study-archtop.air.json) · [portable artifact](a-little-room-between-archtop.refrain.json)

The nylon artifact selects `breath-close-room@1` and retains its original
acoustic binding. The archtop artifact selects `refrain-shinyguitar-archtop@1`
and carries native plus audition-matched RenderReceipt@3/projection references.
Both carry canonical source/receipt and exact performance choices; neither
contains sample binaries. The app README provides build/export commands and the
level-matched comparison boundary. No listening acceptance is claimed.
